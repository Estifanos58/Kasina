# Kasina Frontend Client

This directory contains the React 18 + Vite frontend client for the Kasina real-time messaging application.

For complete project documentation including architecture, Docker instructions, environment variables, and backend configuration, refer to the root [README.md](../README.md).

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run ESLint
npm run lint

# Run unit tests
npm test

# Build for production
npm run build
```
